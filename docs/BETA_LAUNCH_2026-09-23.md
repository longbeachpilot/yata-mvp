# YA TA 예약 베타 실행표 — 2026-09-23

이 문서는 운영 준비용입니다. 정식 약관이나 개인정보처리방침이 아니며, 빈 항목이 남아 있는 상태에서 공개 고객 모집을 시작하지 않습니다.

## 첫 운영 범위

- 제안: 실제 제휴 학원 1~2곳, 확정된 서비스 지역, 초대 고객 10~20명으로 제한합니다. 제휴·모집 완료를 의미하지 않습니다.
- 현재 제품: 교관 탐색, 예약 요청, 교관 확정, 수업 기록, 후기. 플랫폼 결제·환불·정산은 미구현입니다.
- 결제 없이 기능만 시험할지, 학원이 직접 결제받는 실제 수업을 운영할지 먼저 확정합니다. 후자는 교육 제공자, 결제 수취인, 환불 담당과 조건을 고객에게 예약 전에 안내할 수 있어야 합니다.
- 예약 요청과 확정을 구분하고, 요청 단계에서 수업이 확정됐다고 안내하지 않습니다.

## 실제 계정 확인 순서

운영자가 관리하는 학습자와 교관 계정으로 실행합니다. 테스트 예약은 학원과 사전에 구분하고, 인증 링크·비밀번호·고객 개인정보를 공개 저장소에 올리지 않습니다.

| 단계 | 조작 | 확인할 결과 | 결과 |
|---|---|---|---|
| 1 | 출시 도메인 회원가입 및 이메일 인증 | 메일 수신, 같은 도메인 복귀, 로그인 성공 | 미실행 |
| 2 | 비밀번호 복구 | 복구 메일 수신, 변경 후 새 비밀번호 로그인 | 미실행 |
| 3 | 모바일 교관 검색 및 지도 재방문 | 카카오맵 표시, 실제 서비스 지역 일치 | 미실행 |
| 4 | 로그아웃 상태에서 날짜·시간·장소 선택 후 로그인 | 선택값 복원, 동일 교관·금액 | 미실행 |
| 5 | 학습자 예약 요청 | 내 예약에 요청 상태 1건, 교관에게 같은 예약 표시 | 미실행 |
| 6 | 교관 확정 | 학습자·교관 양쪽 상태 일치 | 미실행 |
| 7 | 별도 테스트 예약 취소·거절 | 양쪽 상태 일치, 재예약 가능 여부 확인 | 미실행 |
| 8 | 사전 합의한 테스트 수업 완료 및 로그북 작성 | 학습자 기록과 후기 작성 연결 확인 | 미실행 |
| 9 | 두 번째 학습자 계정으로 확인 | 다른 사용자의 예약·비공개 정보에 접근 불가 | 미실행 |

기존 모의 API 브라우저 검사와 실제 DB 회귀 검사는 이 확인을 대신하지 않습니다. 실제 수업 전에는 서비스 대상, 학원·교관·차량·보험 조건이 해당 운영 방식에 맞는지 확인해야 합니다.

설립 예정 회사와 현재 운영주체를 혼동하지 않습니다. 사업자등록증·보험증권·교관 자격자료는 공개 저장소에 첨부하지 않습니다. 위 정보 확정 후 `/terms`, `/privacy` 및 예약 안내를 실제 운영에 맞춰 교체합니다.

## 첫 주 운영

1. 운영 시작 전: 향후 7일 일정·가격을 학원과 대조하고, 응답 담당이 실제로 접속할 수 있는지 확인합니다.
2. 매일: 미확정 요청, 중복·취소 문의, 수업 완료·기록 누락을 점검합니다. 자동 알림이 된다고 가정하지 말고 합의된 연락 채널을 사용합니다.
3. 첫 10건: 요청→확정→완료 건수, 취소 사유, 최초 응답 시간, 고객 문의를 기록합니다. 테스트와 실제 거래는 구분합니다.
4. 중단 기준: 타인 정보 노출, 중복 확정, 가격 불일치, 실제 제공 불가능 일정이 확인되면 신규 접수를 멈추고 영향 범위를 확인합니다. 예약 기록을 삭제해서 해결하지 않습니다.
5. 확대 조건: 미해결 중대 오류가 없고, 첫 고객의 예약·확정·수업·후속 안내가 완료된 뒤 지역과 학원을 늘립니다.
